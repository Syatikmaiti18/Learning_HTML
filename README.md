# Learning_HTML

This repository contains all the **HTML files, examples, exercises, and small projects** that I created while learning HTML through tutorials and hands-on practice.

The main purpose of this repository is to keep track of my **HTML learning journey**, practice different HTML concepts, and build a strong foundation in web development.

## 📖 About This Repository

HTML (HyperText Markup Language) is the standard markup language used to create and structure content on web pages. During my learning process, I practiced various HTML elements, attributes, forms, tables, lists, multimedia elements, and other important concepts.

This repository contains the files and folders that I created while following HTML tutorials and experimenting with different concepts.

I have tried to keep the examples simple and beginner-friendly so that they can also be useful for revising HTML concepts later.
